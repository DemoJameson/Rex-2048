How it works

选集不是剧集，是按键。

Rex 把七个操作识别成七集。选中某一集，模块向服务端提交一次命令；服务端更新棋局并推出一条新的视频流。

从打开到落子

  1. 1
    导入模块点击“导入到 Rex”，在 Rex 确认框中完成导入。
  2. 2
    确认服务端通过本页导入时，模块会自动使用当前服务端地址。
  3. 3
    加入首页把 Rex 2048 添加到首页，然后打开播放。
  4. 4
    开始操作在播放器内打开选集，选择 1 开局，再用 2–7 操作。

退出播放器后重新打开模块即可继续当前棋局。不要点第 1 集，除非你想重新开局。

Built for Rex

为播放器而生的 2048。

它不只是一段视频。每一局都有独立状态、动画、音效和持久化进度，服务端负责渲染，Rex 负责播放。

◈

实时棋盘

服务端维护 4×4 棋盘、合并、计分、撤销和胜负状态，画面持续更新。

↯

硬件编码

优先使用 VideoToolbox、NVENC 或 VAAPI；没有硬件时自动回退 libx264。

◎

独立棋局

每个 Rex 安装生成自己的匿名 token，多人可以各自游玩，互不影响。

文

三语界面

简体中文、English、繁體中文，默认简体中文，棋盘文案与选集标题同步切换。

⌁

退出可续玩

棋局和分数写入服务端存储，重新打开模块会回到当前进度，不用从头开始。

✦

小恐龙与彩蛋

像素小恐龙、滑动合并动画、不同方向音效，以及一个值得自己发现的隐藏结局。

Run it

本机、局域网或 Docker，都能跑。

默认只需要公开 API 端口 18081；视频流和 RTMP 留在服务端内部。公网通过 ESA 时固定 PUBLIC_BASE_URL，并只回源 18081。

本地原生运行

适合在 Mac 上直接测试，优先使用 VideoToolbox 硬件编码。

npm install npm run server
需要 Node.js 20+ 与 FFmpeg。默认地址：http://127.0.0.1:18081

Docker 局域网部署

单容器运行 API、NMS、FFmpeg 与 Canvas，适合多台 Rex 设备共享。

cp .env.example .env docker compose up -d --build
建议设置 ADMIN_TOKEN；IPv6 回源用 API_BIND=:: 和 API_PUBLISH=[::]:18081。

Install

现在就把棋盘带进 Rex。

导入链接会调用 Rex 的模块导入确认框。模块会默认使用 当前页面地址 作为服务端地址，导入后加入首页即可开始。

导入到 Rex 需要 macOS 上的 Rex 1.1+。若浏览器没有唤起 Rex，请复制模块地址，在“设置 → 模块 → 导入的模块”中手动添加。
